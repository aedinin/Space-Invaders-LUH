# Space Invaders - GIP Spieleprojekt (WiSe 26/27)

Terminal-based Space Invaders game in Python 3.
Standard library only, no GUI framework.

## Run

    python main.py

## Structure

- `main.py` - entry point, game loop (30 FPS, dt-based)
- `game/config.py` - global constants
- `game/states.py` - state machine (MENU / RUNNING / PAUSED / GAME_OVER)
